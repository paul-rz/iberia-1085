# Iberia hacia 1085

Mapa interactivo de la península ibérica hacia el año 1085 (tras la toma de Toledo), con relieve, reinos, condados y taifas, fichas históricas y un juego de trivia.

Una sola página (`index.html`): HTML, CSS y JavaScript con [Leaflet](https://leafletjs.com). Necesita conexión para cargar las capas de relieve.

Las fronteras son aproximadas.
